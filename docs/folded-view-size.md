# 접기 모드 250×300px 크기 조절

v2.18에 포함된 변경이다. v2.17 패키지는 이 변경을 포함하지 않는다.

**위치 · OBS → 키뷰어 접기 → 가로 250 / 세로 300 → 적용 + 저장**으로 설정한다. 접기 상태의 가로·세로 입력은 표시 픽셀 크기를 뜻하며, 폭을 다시 1.5배로 늘리지 않는다. 최소 폭은 접기 250px, 일반 모드 650px이고 최소 높이는 모두 300px이다. JSON/INI에서도 같은 제한을 적용한다.

900px 미만의 접기 화면은 실시간·완료 측정값, NPS·4K LN, 보조지표 여섯 개를 세로로 배치한다. 보조지표 이름을 줄이지 않고 150% 글꼴 변환을 유지한다. 보조값이 이전 완료 결과인지 측정 중인지도 표시한다. 큰 폭에서는 기존 지표 배치를 사용한다. 글꼴 크기는 창 축소 비율과 독립적이며 긴 주 지표 문자열은 기존처럼 공간에 맞는 글꼴을 선택한다.

기본 실타건 지표는 250×300px에 들어간다. 사용자가 별도로 켠 osu! 선곡 지표나 이동 모드 안내가 있으면 내용을 자르지 않도록 실제 높이가 설정 높이보다 커질 수 있다. OBS 캡처의 크기와 자르기는 변경된 표시 크기에 맞춘다.

접기 상태에서 10% 축소/확대는 창만 조절하며 노트 크기·이동 거리·진행 중인 입력은 유지한다. 접기를 끄거나 분석/HUD를 끌 때 폭이 650px 미만이면 일반 모드의 650px로 보정한다. 크기를 직접 수정하지 않고 접기만 켰다 끄면 기존 설정 크기는 그대로다.

검증은 250×300 실제 숨김 창, 폭/높이 하한 거부, 10% 축소 하한, JSON/INI 저장·복원, 일반 모드 복원, 250/400/650/900/1350px 자체 렌더링과 최소 폭에서 여섯 이름·세 자리 값의 글꼴 유지로 수행한다. 실제 게임·OBS·다른 DPI 환경은 별도 확인이 필요하다.
