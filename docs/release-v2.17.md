# v2.17 — 키뷰어 접기 · 자동 키 수 보정 · 보조 완료값 수정

2026-10-29 Windows x64. 일반판과 NoOsuMemory를 제공한다.

## 키뷰어 접기

**위치 · OBS → 키뷰어 접기 · 지표 글자 150% → 적용 / 적용 + 저장**으로 켠다. 키·레인·노트·롱노트 애니메이션을 숨기고 주 지표, 완료 측정값, NPS, 4K LN 비교와 여섯 보조지표만 표시한다. 활성화한 선곡 연동 지표도 함께 표시한다.

모든 HUD 글꼴과 배치를 150%로 함께 그린다. 큰 단수뿐 아니라 제목, NPS, LN, 스킬 이름과 수치, 선곡 설명 및 이동 모드 안내까지 확대한다. 글자가 다시 작아지거나 겹치지 않도록 가로폭도 150%가 되며, 세로는 지표에 필요한 높이만 사용한다. 표시 폭 650px은 975px, 900px은 1350px이 된다. OBS의 기존 자르기·크기 맞춤은 실제 캡처 크기에 맞춰 확인한다.

저장된 가로·세로와 노트 크기·키 배치는 바꾸지 않는다. 접기만 전환할 때 입력 수집·누르고 있는 키·분석·완료값을 유지하며, 해제하면 원래 표시 크기로 돌아간다. JSON/INI의 `overlay.key_viewer_folded`는 기본 `false`/`0`이며 이전 설정에는 꺼짐으로 적용된다. 분석 또는 HUD 표시가 꺼져 있으면 접기를 적용하지 않고 기존 키뷰어를 표시한다. 분석이나 기록 옵션을 자동으로 켜지 않는다.

## 자동 키 수 보정

이전 자동 모드는 초반에 관측한 키 수로 고정한 뒤 추가 키가 등장하면 연주가 끝날 때까지 보류했다. 이제 **자동 추정 · 추가 키 보정**에서 새 키가 나오면 `키 보정 중`으로 표시하고, 관측한 모든 키가 두 번 이상 눌렸으며 마지막 새 키 이후 3초가 지나면 관측 수로 보정한다. 처음 확정할 때의 최소 8초·32회 입력 조건은 유지한다. 한 연주 안에서는 관측 키 수가 줄지 않으며 10초 무입력 뒤 새 연주에서 다시 추정한다.

보정할 때 이전 키 수의 완료 후보와 비동기 결과를 제거한다. 입력 이력은 유지해 주·보조지표가 새 기준으로 이어진다. 선택적으로 켠 자동 리포트는 분석 기준이 바뀔 때 구간을 나눈다. 추가 키가 확인되지 않은 채 연주가 끝나면 잘못된 이전 키 수로 새 완료값을 확정하지 않는다. 수동 고정은 그대로 유지하며 자동 지원 범위를 넘는 11개 이상 입력은 명시적으로 보류한다.

관측하지 않은 키와 등록하지 않은 키는 알아낼 수 없다. 자동 추정은 4~10K이며, 키마다 한 번만 누르거나 시작 후 8초가 지나지 않으면 계속 수집한다. 해당 조건과 새 키 없이 3초 대기 조건을 설정 창에 표시한다. [분석 키 수 상세](analysis-key-mode.md)

## 보조 완료값

비동기 보조 결과에 수신 시점의 주 난이도를 붙이면 초반 결과가 뒤쪽의 최고 난이도를 차지할 수 있었다. 계산 요청 시점의 유효한 주 난이도를 해당 보조 결과와 묶어 저장하도록 수정했다. 더 강한 구간의 결과가 `유지` 중 도착해도 완료 후보를 교체한다. 여섯 특징 수식, 주 난이도 수식, 170ms 홀드 추정, 최근 8초/0.5초 보조 갱신과 마지막 입력 후 10초 완료 조건은 유지한다. [재현과 수정](completed-results-hotfix.md)

## 검증 범위

합성 입력으로 초반 보조값 고정과 추가 키 이후 자동 모드의 복구 실패를 각각 재현했다. 접기 설정의 JSON/INI 저장·복원, 실제 숨김 창의 접기/복원 크기, 키·노트 픽셀 제외, 누르고 있는 입력 유지, 분석/HUD 꺼짐, 650/900px 기준 확대 렌더링을 검사한다. 자동 4→5→7키 보정, 재추정 대기, 11키 보류, 수동 기준 유지, 보정 후 완료값을 검사한다.

정확한 빌드·테스트 수와 소스 커밋은 배포 ZIP의 `VERIFICATION.md` 및 `SOURCE-SHA256SUMS.txt`에 기록한다. 실제 게임·OBS 캡처·다른 PC/DPI·장시간 사용은 미검증이다. 타건만으로 채보의 LN이나 미사용 키 수를 확정할 수 없고, 지표는 개인의 실력·정확도·합격 여부를 측정하지 않는다.

이전 프로그램·설정을 보존하고 새 폴더에 풀어 실행한다. 기존 배치를 이어 쓰려면 프로그램을 종료한 뒤 기존 JSON/INI 설정을 새 폴더로 복사한다. 일반판의 osu! 선곡 연동은 매 실행 OFF이며 NoOsuMemory는 메모리 리더와 선곡 UI를 포함하지 않는다.
