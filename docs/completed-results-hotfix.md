# 완료 화면 핫픽스 — 2026-10-28

v2.16.1은 이 완료값 수정과 함께 **최소 창 크기 650×300px**를 적용한다. 기존 소형 HUD 렌더러는 회귀검사에 남기지만 새 설정으로 650px 미만 폭을 적용할 수 없다. 보조지표는 v2.16처럼 최근 8초 입력을 0.5초마다 계속 갱신하며, 유효한 실시간 보조값이 있으면 완료값보다 먼저 표시한다.

## 원인과 변경

- 기존 좁은 HUD는 실시간 LN만 표시하고 완료 LN을 폭 600px 이상에서만 덧붙였다. 실시간 값이 사라지면 폭 450px에서는 `측정 대기`로 보였다. 이제 실시간 LN이 없으면 모든 폭에서 `완료 ○단`을 표시한다.
- 보조지표 계산기는 최근 8초 입력만 사용하므로 입력이 사라지면 여섯 칸이 `—`로 돌아갔다. 이제 주 난이도와 같은 10초 무입력 완료 시점에 유효한 보조값을 별도로 보존한다. `보조지표 · 완료`는 이전 연주의 결과임을 뜻한다.
- 완료 뒤 짧은 입력이 들어와 `분석 중`이 되어도 새 보조값이 준비되기 전에는 완료값을 유지한다. 유효한 새 실시간 결과가 생기면 실시간으로 전환하고, 그 연주가 완료되면 새 완료값으로 교체한다.
- 계산이 늦게 도착해 주 난이도가 유지 상태가 된 경우에도 그 연주의 첫 유효 보조값을 보존한다. 새 주 난이도가 완료됐지만 보조 계산이 전부 실패했다면 이전 연주의 수치를 새 결과로 표시하지 않는다.

보조 완료값은 관측한 높은 주 난이도 구간 주변의 CPP 특징이다. 별도 비동기 계산이므로 주 난이도 최고 시점과 완전히 일치하지 않으며 곡 전체 평균이나 플레이어 실력이 아니다. 주 난이도, 4K LN 비교 수식, 170ms 홀드 판정, 10초 완료 기준은 유지한다. 결과는 메모리에만 보관하고 분석 초기화·키 배치/모드 변경·앱 종료 시 지운다.

## 사용

`KeyNoteOverlayCpp-v2.16.1-Windows-x64.zip` 또는 `KeyNoteOverlayCpp-v2.16.1-NoOsuMemory-Windows-x64.zip`을 새 폴더에 풀고 `KeyNoteOverlayCpp.exe`를 실행한다. NoOsuMemory는 기존처럼 게임 메모리 리더와 선곡 연동 UI를 제외한다. 일반판 선곡 연동은 매 실행 OFF다.

기존 프로그램을 종료한 뒤 사용하던 `key_note_cpp_config.json`과 `key_note_cpp_config.ini`를 새 폴더에 복사하면 배치를 이어 쓸 수 있다. 이전 프로그램·설정을 보존한다. 기본 배포 배치는 8K이므로 4K 플레이에는 4K 배치 또는 해당 분석 키 설정을 사용한다.

Discord 등 외부 앱의 채팅을 분석에서 제외하려면 **위치 · OBS → 게임용 모드 → 적용 + 저장**을 켠다. 게임용 모드가 꺼져 있으면 다른 앱의 등록 키 입력도 분석한다. 게임 내부 채팅과 실제 연주를 구분하는 기능은 없으며, 완료 전 10초 안에 등록 키를 누르면 완료 시점이 늦어질 수 있다. 이번 수정은 입력 필터를 바꾸거나 게임용 모드를 자동으로 켜지 않는다.

## 확인 방법

1. HUD 크기를 650×300px로 설정하고 4K에서 유효한 입력을 충분히 수집한다. 이전 450px 설정은 불러올 때 650px로 보정된다.
2. 키를 모두 놓고 10초 기다린다. `완료` 레벨, `4K LN`의 `완료 ○단`, `보조지표 · 완료`의 여섯 값이 함께 남는지 확인한다.
3. 게임용 모드 OFF에서 등록 키를 한두 번 누른다. 실시간은 `분석 중`이어도 이전 완료 LN과 보조값은 유지되어야 한다.
4. 다음 연주를 시작하면 유효한 실시간 보조값으로 바뀌고, 다음 완료 시 새 결과로 교체되어야 한다. 분석 초기화 후에는 이전 완료값이 없어야 한다.

자동 검사는 실제 입력 수집 함수에 합성 누름/해제를 전달해 위 전환과 170ms 홀드값을 확인한다. 650px에서 완료값·계속 갱신되는 실시간 값을 렌더링하며, 기존 240·450·900px 자체 렌더러 검사도 유지한다. 외부 키 입력 전송이나 화면 캡처는 하지 않는다. 실제 게임·OBS 캡처·다른 PC/DPI의 동작은 별도 확인이 필요하다. 패키지별 빌드·테스트 결과는 `VERIFICATION.md`에 기록한다.
