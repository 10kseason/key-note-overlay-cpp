# 개인정보와 라이선스

## 실행 중 입력과 저장

오버레이는 Windows 키보드 훅에서 등록된 키의 누름·뗌을 받아 레인별 시각과 난이도를 계산한다. 등록되지 않은 키는 표시·분석하지 않는다. 입력 문자열·게임 화면·게임 메모리·판정·채보 파일을 읽거나 외부 서버로 전송하는 기능은 없다.

일반 OBS 모드는 다른 앱에서 누르는 등록 키도 관측한다. 게임용 모드를 켜면 osu!/Qwilight가 앞에 있을 때와 설정의 난이도 연습 입력으로 범위를 제한한다. 게임 메뉴나 채팅과 실제 연주는 구분하지 않는다. 분석이 필요하지 않을 때는 난이도 분석을 끄거나 앱을 종료할 수 있다.

자동 리포트는 기본 꺼짐이다. 켜면 로컬 시작 시각, 키 수, 레인별 타이밍, 난이도 지표를 `reports` 아래 HTML로 저장한다. 실제 키 이름·입력 문자열·활성 창 제목은 리포트에 넣지 않는다. 타건 시각과 연주 패턴도 사용 기록이므로 리포트를 공유하기 전에 확인한다. 설정 JSON/INI에는 선택한 키 배치·색상·창 위치 등이 저장되며 배포 예제와 별개인 개인 설정이다.

게임 감지는 전경 프로세스의 실행 파일명을 조회한다. 경로나 창 제목을 리포트에 넣지 않는다. 네트워크 전송·텔레메트리·자동 업데이터·시작 프로그램·서비스를 추가하지 않는다.

## 공개 패키지 점검

공개 ZIP은 예제 기본 설정과 검증된 EXE·문서·라이선스·합성 리포트만 포함한다. 개인 설정, 실제 연주 리포트, 스크린샷, 로그, 덤프, 원본 채보·음원·이미지, 디코더 JAR 및 절대 경로가 포함된 분석 중간 파일은 포함하지 않는다. Git에는 배포 대상 소스·테스트·도구·집계 자료만 명시적으로 선택한다.

v2.12 공개 전에는 선택한 소스와 Git 이력, 커밋 메타데이터, EXE 문자열, ZIP 파일 목록을 검사했다. 사용자 홈·PC 이름·개인 이메일·주요 자격 증명 패턴은 발견되지 않았다. Git 메타데이터의 예제용 로컬 주소·GitHub 자동화 주소는 개인 이메일로 분류하지 않았으며 기존 공개 이력은 보존했다. 새 공개 커밋은 GitHub noreply 주소를 사용한다. 패턴 기반 정적 검사이므로 모든 형태의 비밀값 부재를 보증하지 않는다.

- osu!mania strain에서 가져와 조정한 코드: ppy의 MIT 고지를 [osu-LICENCE.txt](../third_party/osu-LICENCE.txt)에 보존한다. 기준 원본은 [ppy/osu의 명시된 리비전](https://github.com/ppy/osu/blob/c752ffb2260abcf4dad0b7d8e298806ab9db5b24/LICENCE)이다.
- 정적 링크한 GCC·MinGW-w64·winpthreads 런타임: [런타임 고지](../third_party/toolchain-NOTICE.md)와 `third_party/toolchain/`의 원문을 함께 제공한다. GCC Runtime Library Exception을 포함한 외부 고지는 프로젝트 MIT 표기로 대체하지 않는다.
- beatoraja 디코더: 오프라인 검증 도구에서 별도 설치본을 사용할 수 있으나 오버레이 EXE·ZIP에 JAR나 디코더 바이너리를 포함하지 않는다. 별도 설치본의 이용·재배포에는 해당 프로젝트 라이선스를 따른다.
- 기준 채보: 곡명·채보명·해시와 파생 집계만 제공한다. 채보·음원·이미지의 권리를 MIT로 바꾸거나 재배포 허가를 부여하지 않는다.

공유할 때는 EXE만 떼어 배포하기보다 고지가 포함된 ZIP을 사용한다.
