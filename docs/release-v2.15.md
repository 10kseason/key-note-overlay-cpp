# v2.15 — 보조지표·큰 글씨·홀드 오인식 수정

2026-10-28 Windows x64 릴리즈.

## 변경

- 오버레이를 10%씩 축소/확대하고 레인 간격을 조절할 수 있다. 측정 레벨은 최대 48px, 보조지표 이름은 22px, 스킬 수치는 26~32px, 4K LN 결과는 최대 32px로 표시한다. 좁은 폭에서는 줄을 나누고 모든 지표와 노트 영역을 표시할 높이를 확보한다.
- 보조지표 6칸을 모두 표시한다. 원본 키별 일반 배치 행렬로 1~18K를 지원하며, 제목은 `보조지표`와 `채보 보조지표`로 구분한다. CPP 값은 LV가 아닌 0~100 특징 강도다.
- **실시간 홀드 오인식 수정:** 90ms 이상 누른 단타를 가상의 LN으로 만들던 처리를 제거했다. 타건만으로 실제 LN을 알 수 없어 실시간 홀드는 `—`(미확인)로 표시하고, 나머지 5개는 누름 시점으로 계산한다. 선택 채보의 홀드는 실제 파일 LN만 반영하므로 LN이 없는 파일은 0이다.
- 4K LN Dan Courses v2 원본 1~15단의 비교를 일반 Reform과 별도로 표시한다. 모델에서 역전되는 3·4단은 `3~4단`으로 묶는다. 주 난이도·4K LN 단위 비교의 기존 입력 추정 방식은 이번 홀드 수정으로 바뀌지 않는다.
- 등록 키 배치와 분석 기준을 분리한다. 자동 추정·세션 고정 또는 수동 4~10K를 선택할 수 있으며, 사용 레인이 확정되면 원래 순서와 간격을 유지해 표시한다. 1~3K·11~18K는 직접 키를 등록하고 `등록 키 수 (기존)`을 사용한다.
- osu! 선택 파일과 독립 파일 계산기는 0.1초 평가·누름 직전·파일 끝을 포함해 실시간 방식의 유효 최고 구간을 계산한다. 파일 계산기도 4K LN 비교를 표시한다.

## 패키지

- `KeyNoteOverlayCpp-v2.15-Windows-x64.zip`: 일반판. osu! 선곡 연동은 매 실행 OFF이며 직접 위험 동의 후 켤 수 있다.
- `KeyNoteOverlayCpp-v2.15-NoOsuMemory-Windows-x64.zip`: 게임 메모리 리더와 연동 UI를 컴파일에서 제외한 판. 입력 오버레이와 실시간 보조지표는 유지한다.
- `ChartDifficultyCalculator-v2.15-Windows-x64.zip`: `.osu`와 지원 BMS 파일을 직접 여는 독립 계산기.
- `KeyNoteOverlayCpp-v2.15-SHA256SUMS.txt`: 세 ZIP의 SHA-256. 각 ZIP 내부에도 파일별 체크섬이 있다.

새 폴더에 압축을 풀어 실행한다. 오버레이에는 개인 설정 대신 기본 8K 예제 설정을 넣었다. 기존 설정을 사용하려면 기존 프로그램을 종료한 뒤 JSON/INI를 별도로 복사한다. 기존 릴리즈 자산을 교체하지 않는다.

## 검증

- 공개 대상만 담은 격리 소스에서 GCC 15.1 / CMake Release / 정적 런타임으로 재빌드했다.
- 일반판 CTest **11/11**, NoOsuMemory **11/11**, 독립 계산기 **3/3** 통과.
- CPP 원본 대조 **2,565개 검사**: 1~18K 합성 입력 167종의 6축과 내부 계산값 일치. 새 홀드 표시 처리는 원본 파일 계산 수식을 변경하지 않는다.
- 실시간 **177개 검사**: 느린 단타 해제 90/95/120/200/500ms의 오인식 회귀, 열린 키, 창 경계, 포커스 해제, 키 모드 변경, 비동기 결과 폐기를 포함한다.
- osu! 파일 경계 **58개 검사**: 1~18K에서 LN 없는 파일의 홀드 0과 실제 20ms LN 파일의 양수 값을 구분한다. 실제 게임 메모리는 읽지 않았다.
- 네이티브 UI 일반판 **261개**, 메모리 제외판 **245개** 검사 통과. 큰 글씨·최소 폭 240px·홀드 미확인·선택 채보 값·설정·트레이·리포트 경로를 확인한다.
- Python 26개 중 **24개 통과, 2개 제외**. 별도 beatoraja Java 디코더 통합 검사는 의존성이 없어 제외했다. 최초 임시 폴더 권한 오류는 작업 폴더 안의 임시 위치로 옮겨 재검사했다.
- NoOsuMemory의 게임 메모리 읽기 API와 osu! 리더 심볼 부재를 확인했다. 소스·실행 파일의 개인 경로와 주요 자격 증명 패턴, 새 커밋 메타데이터, 배포 파일 목록을 검사했다. 정적 패턴 검사는 모든 민감정보 부재의 증명이 아니다.

실제 게임 플레이·OBS 송출·다중 DPI·다른 PC·장시간 실행은 이번 릴리즈 검사 범위 밖이다. 원본 수치 일치는 체감 난이도·플레이어 실력·클리어 예측 정확성을 뜻하지 않는다. 고정 배치·Qwilight EZ 조건이며 osu! OD와 게임 모드는 반영하지 않는다. 비공식 메모리 연동의 안티치트 안전성을 보장하지 않는다.
