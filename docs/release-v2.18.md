# v2.18 — 설정창 캡처 허용 · 접기 250×300px

2026-10-29 Windows x64. 일반판과 NoOsuMemory를 제공한다.

## 설정창 캡처

설정창에 적용하던 Windows 캡처 제외 옵션을 제거했다. 설정창의 표시 선호도는 기본값 `WDA_NONE`이며, 스크린샷과 화면 공유에서 설정창을 포함할 수 있다. 또한 창 캡처 선택 목록에서 제외될 수 있는 도구 창 스타일을 일반 앱 창 스타일로 바꿨다. 설정창은 작업 표시줄과 Alt+Tab에도 나타날 수 있다.

설정창을 직접 캡처하려면 **Key Note Overlay C++ Settings** 창을 선택한다. 키·노트와 지표만 캡처하려면 기존 **Key Note Overlay C++ Overlay**를 선택한다. 설정창 닫기·트레이 복원·게임 밖 입력 제외 동작은 유지한다.

## 접기 크기 조절

**위치 · OBS → 키뷰어 접기 → 가로 250 / 세로 300 → 적용 + 저장**으로 최소 250×300px까지 조절한다. 입력한 폭이 실제 픽셀 크기이며, v2.17처럼 표시 폭을 다시 1.5배로 늘리지 않는다. 일반 모드는 최소 650×300px를 유지한다.

900px 미만의 접기 화면에서는 실시간·완료 측정값, NPS·4K LN, 여섯 보조지표를 세로로 배치한다. 글꼴 150% 변환을 유지하고 보조지표 이름을 줄이지 않는다. 창의 10% 축소/확대는 노트 크기·이동 거리와 독립적이다. 접기 크기만 바꿀 때 입력·홀드·분석 결과를 유지한다.

접기를 해제하거나 분석/HUD를 끌 때 폭이 650px 미만이면 일반 모드의 최소 폭으로 보정한다. 별도로 켠 선곡 지표와 이동 안내는 추가 높이를 사용할 수 있다. [사용 방법과 배치](folded-view-size.md)

## 검증

실제 생성 경로를 공유하는 숨김 설정창에서 캡처 제외 없음, 일반 앱 창 스타일 및 독립된 최상위 창임을 확인한다. 네이티브 설정·트레이 수명주기 검사와 일반판/NoOsuMemory 전체 테스트를 수행한다. 250×300 실제 창 크기, 크기 하한, JSON/INI 저장·복원, 일반 모드 복원, 여섯 이름·세 자리 값의 확대 글꼴 유지와 다섯 폭의 자체 렌더링도 검사한다. 최종 결과와 소스 커밋은 ZIP의 `VERIFICATION.md`에 기록한다.

두 배포 ZIP의 추출 실행 파일과 파일 해시·CRC를 검증한다. 실제 OBS/Discord 캡처·게임·다른 PC/DPI의 동작은 별도 확인이 필요하다. 이전 릴리즈와 설정은 보존한다.
