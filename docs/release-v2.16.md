# v2.16 — 실시간 홀드(LN) 170ms 판정

2026-10-28 Windows x64 릴리즈.

## 변경

- 실시간 `보조지표`에서 **170ms 이상 누른 입력을 홀드(LN)로 추정**한다. 170ms 미만은 단타다. v2.15의 홀드 미확인(`—`) 대신 계산한 수치와 막대를 표시하며, 해당 입력이 없으면 홀드 0이다.
- 누르고 있는 키도 관측 시간이 170ms에 도달하면 다음 계산에 반영한다. 기존 최소 8회 입력·1.5초 관측, 0.5초 갱신 주기를 유지한다.
- 홀드로 분류한 입력은 누른 시점부터 관측된 끝까지 사용한다. 최근 8초 창보다 먼저 시작했다면 창에 남은 구간만 포함한다. 반복 입력은 시작 시각을 바꾸지 않으며 포커스 해제 시 열린 홀드를 닫는다.
- 일반판과 NoOsuMemory 모두 1~18K의 여섯 스킬을 계산한다. 선택 채보 보조지표는 파일의 실제 LN을 사용하므로 170ms보다 짧은 실제 LN도 계속 계산한다.

입력 지속 시간은 실제 채보의 LN 존재 여부를 확정하지 않는다. 변경은 실시간 CPP 보조지표의 입력 추정에 적용하며 주 난이도와 4K LN 단위 비교 수식은 유지한다.

## 다운로드

- `KeyNoteOverlayCpp-v2.16-Windows-x64.zip`: 일반판. osu! 선곡 연동은 매 실행 OFF이며 직접 동의해야 켜진다.
- `KeyNoteOverlayCpp-v2.16-NoOsuMemory-Windows-x64.zip`: 게임 메모리 리더와 연동 UI를 컴파일에서 제외한 판.
- `KeyNoteOverlayCpp-v2.16-SHA256SUMS.txt`: 위 두 ZIP의 SHA-256. 각 ZIP 내부에도 파일별 체크섬이 있다.

새 폴더에 풀어 `KeyNoteOverlayCpp.exe`를 실행한다. 배포 설정은 기본 8K다. 기존 설정을 사용하려면 실행 중인 프로그램을 종료한 뒤 JSON/INI를 별도로 복사한다. 이전 릴리즈와 로컬 패키지는 보존한다.

## 검증

- 격리한 배포 소스에서 GCC 15.1 / CMake Release / 정적 런타임으로 빌드.
- 일반판 CTest **11/11**, NoOsuMemory **11/11** 통과.
- 실시간 **254개 검사** 통과: 169.999/170/170.001/250/500ms, 열린 키·중복 입력, 창 경계·포커스 해제, 키 모드·비동기 취소, 전체 키 수의 6축과 희소 레인 대응.
- 네이티브 UI 일반판 **279개**, NoOsuMemory **263개** 통과. 실제 입력 수집 경로에서 짧은 입력의 홀드 0과 170ms 입력의 양수 값을 확인했다.
- 기존 원본 계산 대조와 osu! 파일 경계 검사도 통과했다. NoOsuMemory 실행 파일의 메모리 읽기 API와 osu! 리더 심볼 부재를 확인했다.

실제 게임 플레이·OBS 캡처·다중 DPI·장시간 사용은 이번 검사에 포함하지 않았다. CPP 수치는 플레이어 LV가 아닌 입력/채보 특징 강도다. 관련 범위는 [스킬 계산](revive-cpp-auxiliary.md), [NoOsuMemory](no-osu-memory.md), [개인정보·라이선스](privacy-and-licenses.md)에 기록했다.
