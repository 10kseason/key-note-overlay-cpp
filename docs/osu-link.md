# osu! 선택 채보 연동 (실험 기능)

## 이 기능의 위험부담은 전부 사용자 몫입니다!!!

**비공식 프로세스 메모리 조회 기능입니다. 읽기 전용이어도 안티치트 제재·계정 불이익이 없다고 보장하지 않습니다.** 위험을 받아들이는 사용자만 직접 켜세요. 이 안내가 게임 운영사의 허용이나 안전성 인증을 뜻하지 않습니다.

## 사용

1. 설정의 **osu! 연동** 탭에서 빨간 큰 경고를 읽습니다.
2. **위험 안내를 확인하고 이번 실행에서만 연동 켜기**를 선택하고 확인창에서 동의합니다. 확인창의 기본 선택은 **아니요**입니다.
3. osu! stable에서 원래부터 mania용으로 만들어진 채보를 고르면 곡명·난이도명·원본 키 수·예상 난이도가 설정과 오버레이의 별도 줄에 표시됩니다.
4. 표준 `Songs` 위치를 쓰지 않으면 **Songs 폴더 지정…**으로 실제 폴더를 고른 뒤 다시 켭니다. 폴더를 바꾸면 연동은 꺼집니다.

**기본 OFF이며, 앱을 다시 실행할 때마다 OFF입니다.** 적용·저장, 이전 설정 복원, 개인 설정 파일로 자동 활성화되지 않습니다. 끄면 작업 스레드와 게임 핸들을 정리하고 선택 곡 표시를 지웁니다. 이전 5K의 34개 보정점과 보조 기준, 기존 입력 분석·키 배치는 바뀌지 않습니다.

## 계산 범위

- 32비트 osu! stable의 로컬 `.osu` 파일만 지원합니다. lazer와 Qwilight 선곡 연동은 지원하지 않습니다.
- **원본 채보 1.00배 기준**입니다. DT/HT/키 수 변경/Co-op 등 게임 모드 변경, 일반 osu!에서 mania로 변환한 배치는 반영하지 않습니다. HUD도 원본 키 수와 모드 미반영을 명시합니다.
- 키 수와 노트·롱노트는 파일에서 읽습니다. 난이도는 기존 계산기의 강한 8초 구간 최대 3개 평균이며 공식 별점·단위 합격·개인 체감의 확정값이 아닙니다.
- 이 줄은 선택 파일의 추정입니다. 기존 실시간 입력 난이도와 현재 NPS는 실제 타건을 계속 따로 계산합니다.
- 높이가 낮은 오버레이에서는 추가 줄이 키 레인을 가리지 않도록 이전 패턴 카드 자리에 선택 채보의 키 수·예상 난이도를 표시합니다. 창 크기나 저장된 위치를 자동으로 바꾸지는 않습니다.
- 변경은 약 0.75초 주기로 확인하며 첫 연결 탐색·파일 분석 시간이 추가됩니다. 새 파일 분석 중, 읽기 실패, 게임 종료, 파일 불일치 때 이전 곡 결과를 현재 곡처럼 표시하지 않습니다. 재탐색에는 최대 약 10초가 걸릴 수 있습니다.

## 구현 경계와 출처

새 C++ 연동 구현은 이 프로젝트에서 작성했습니다. tosu를 실행하거나 API·라이브러리·플러그인을 사용하지 않습니다. 다른 프로젝트의 리더 구현을 가져오지 않았습니다. 호환성에 필요한 32비트 stable의 JIT 검색 바이트와 채보 포인터/문자열 필드 위치라는 **메모리 배치 정보**는 공개 [gosumemory read.go](https://github.com/l3lackShark/gosumemory/blob/master/memory/read.go)의 선언에서 참고했으며, 실제 설치본에서 파일 해시와 교차 확인했습니다. 이를 독립적인 역공학으로 발견했다고 주장하지 않습니다. 기존 strain 구현의 ppy 라이선스 고지는 그대로 유지합니다.

- Windows의 [ReadProcessMemory](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-readprocessmemory)와 [VirtualQueryEx](https://learn.microsoft.com/en-us/windows/win32/api/memoryapi/nf-memoryapi-virtualqueryex)를 사용합니다. 요청 권한은 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`뿐입니다.
- 프로세스 메모리 쓰기, DLL 주입, 디버거 연결, 권한 상승, 안티치트 우회, 화면 캡처, 입력 자동화는 추가하지 않습니다.
- 이름이 `osu!.exe`인 단일 32비트 프로세스만 대상으로 합니다. 여러 개면 연결을 보류합니다. 최초 탐색은 private 실행 영역만, 최대 256MiB/2.5초로 제한합니다. 탐색 바이트·주소는 출력·저장하지 않습니다.
- 채보 객체에서 폴더명·파일명·MD5만 가져옵니다. 문자열 길이와 주소 범위를 검사하고, 선택 포인터를 재확인합니다. 후보가 여러 개거나 호환 검사가 실패하면 추측하지 않습니다.
- 경로 구분자·상위 이동·절대 경로를 금지하고 실제 경로가 Songs 안에 있는지 검사합니다. 외부를 가리키는 junction/symlink, UNC 및 네트워크 드라이브는 거부합니다.
- 게임이 가진 MD5와 파일 해시를 분석 전후 확인합니다. 분석 후 선택 정보가 바뀌면 결과를 게시하지 않습니다. 사용자 이름·채팅·계정 정보·판정은 조회 대상이 아닙니다.
- 선택 채보·폴더 경로·메모리 원문을 설정이나 연주 리포트에 저장하지 않습니다. 곡명은 HUD에 표시되므로 화면 공유에는 보일 수 있습니다. 네트워크 통신·서비스·시작 프로그램은 없습니다.

osu! 업데이트로 메모리 배치가 바뀌면 연동이 멈출 수 있습니다. 이 경우 기능을 끄고 기존 독립 오버레이를 사용할 수 있습니다.

## 확인 방법

`ctest`의 `osu_link_boundaries`는 게임에 연결하지 않고 합성 메모리·임시 파일로 기본 OFF, 동의 거부, 잘못된 포인터·길이·해시·변경 중인 선택, 경로 이탈을 검사합니다. `overlay_settings_workflow`는 숨긴 창에서 경고문·거부 동작·선택 곡 HUD를 검사하며 실제 게임을 읽지 않습니다.

개발용 `osu_link_test --i-accept-memory-read-risk`만 명시적으로 실제 읽기를 수행합니다. `--watch`를 추가하면 50초 동안 곡 변경을 관측합니다. 이 도구와 실제 곡 검증 출력은 배포 패키지에 포함하지 않습니다. 실게임 조회 검증은 안티치트 안전성 검증이 아닙니다.
