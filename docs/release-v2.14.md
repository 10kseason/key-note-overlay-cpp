# v2.14 검증 기록 — 2026-10-26

## 변경

- 트레이 우클릭 메뉴에 임시 최상위 도구 창을 사용한다. 최소화된 설정 창을 메뉴 소유자로 쓰던 문제를 해소하고 메뉴 종료 시 임시 창을 제거한다.
- 설정·설정 소유 대화상자·트레이 메뉴 조작 중에는 게임 모드가 오버레이를 다시 위로 올리지 않는다. 설정은 활성 상태에서만 최상위를 사용하고 다른 앱으로 전환하면 해제한다. 오버레이 표시·렌더링은 유지한다.
- 선택형 osu! stable 선곡 연동을 추가한다. **매 실행 OFF**, 세션별 위험 동의, 원본 mania 파일의 키 수와 예상 난이도 표시. **이 기능의 위험부담은 전부 사용자 몫입니다!!!** 안티치트 안전성을 보장하지 않는다. 범위와 출처는 [osu-link.md](osu-link.md)에 있다.
- 별도 파일 분석 데스크톱 앱 ChartDifficultyCalculator v0.1.0의 소스와 실행 ZIP을 제공한다. 게임 메모리를 읽지 않으며 지원되는 `.osu`·BMS 파일을 직접 선택한다.

## 근거와 한계

- 공개할 파일만 담은 격리 소스에서 Windows x64 Release 빌드 성공. 오버레이 CTest 9/9, 계산기 CTest 3/3 통과.
- 트레이 수명/창 순서 회귀 검사 37개 통과. 실제 Windows 트레이·메뉴 검사 9개 통과: 실제 메뉴의 최상위 표시·메뉴 추적 소유자·오버레이 재상승 억제·아이콘 정리 확인.
- 자동 메뉴 호출에서는 Windows가 전경 포커스를 허용하지 않았다. 최초 검사는 이를 실패로 기록했으며, 사용자 클릭 없는 호출의 포커스 관측을 성공 조건과 분리했다. 최상위 표시와 메뉴 소유자는 실제 Windows 상태로 검사한다. 포커스 제한 우회·입력 자동화는 없다. 실제 사용자의 트레이 마우스 클릭과 게임 독점 전체화면 동작은 별도 확인이 필요하다.
- Python 26개 중 24개 통과, 별도 Java 디코더가 필요한 2개 제외. 최초 임시 폴더 쓰기 권한 실패 후 작업 폴더 내 임시 위치로 재실행했다. 이 릴리즈에서 기준 채보를 재생성하지 않았다.
- 숨긴 자체 창 검사: osu! 기본 OFF, 큰 경고문, 동의창 기본 아니요, 거절 시 비활성 유지, 별도 HUD, 짧은 오버레이 배치 통과. 자체 그리기 이미지를 확인했으며 데스크톱 캡처는 하지 않았다.
- 선곡 기능 개발 중 사용자 동의 아래 실제 stable의 원본 8K 채보를 읽고, 사용자가 고른 원본 4K 채보로 변경되는 것을 확인했다. 로컬 파일 MD5 일치 및 Stop 후 OFF를 확인했다. 실제 곡 이름·파일·메모리 출력은 공개하지 않는다. 이는 안티치트 안전성 검증이 아니다.
- 기존 34개 5K 보정점·230개 보조 채보 기준·10K Revive 기준 및 LN 부담은 변경하지 않았다. `calibration_tables.h`의 Git LF 바이트 SHA-256: `1b11861b677623cabcc324d7a642f3f6020fcd8f8259be9edc39722c72f3aa2b`.
- 오버레이 import 검사: `ReadProcessMemory`, `VirtualQueryEx` 사용. `WriteProcessMemory`, `VirtualAllocEx`, `CreateRemoteThread`, `DebugActiveProcess` import 없음. 파일 계산기에는 게임 메모리 읽기 import도 없다.
- osu! 경로 경계의 합성 검사는 정상 파일·확장자·상위 이동 거부를 확인한다. junction·네트워크 드라이브 거부는 코드 검토 범위이며 실제 장치별 검사라고 주장하지 않는다.
- DT/HT·키 수 변경·Co-op·변환 채보는 미반영, 원본 1.00배 기준이다. lazer/Qwilight 선곡 연동, 다른 PC/DPI, 장시간 실행 및 Discord/OBS 실송출은 검증하지 않았다.

## 공개 범위

소스·새 커밋 메타데이터·EXE·문서·ZIP을 점검한다. 개인 설정, 원본 채보·음원·이미지, 실제 연주 기록, 메모리 출력, 스크린샷 및 테스트 로그는 포함하지 않는다. EXE에는 예제 기본 설정, MIT와 제3자 고지를 동봉한다. 정적 패턴 검사는 모든 형태의 비밀값 부재를 보증하지 않는다. ZIP별 해시는 릴리즈의 `KeyNoteOverlayCpp-v2.14-SHA256SUMS.txt`에서 확인한다.
