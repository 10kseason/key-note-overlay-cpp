# v2.16.1 — 최소 크기·완료 결과 핫픽스

2026-10-28 Windows x64 릴리즈.

## 변경

- 오버레이 최소 크기를 **650×300px**로 제한한다. 직접 입력·10% 축소·화면 중앙 배치·JSON/INI 불러오기와 사용 레인 접기에 적용한다. 기본 크기는 900×300px다. 작은 이전 설정은 메모리에서 보정하며 불러오기만으로 원본 파일을 다시 쓰지 않는다.
- 보조지표는 v2.16과 동일하게 **최근 8초를 0.5초마다 계속 갱신**한다. 이전 완료값이 있어도 유효한 실시간 값이 우선한다. 주 난이도·4K LN 비교 수식과 170ms 홀드 기준은 유지한다.
- 마지막 입력 후 10초 무입력으로 연주가 끝나면 `4K LN` 완료값과 여섯 보조지표를 보존한다. `보조지표 · 완료`는 이전 연주의 값이다. 짧은 새 입력의 수집 단계에서도 이전 완료값이 사라지지 않는다.
- 비동기 계산이 늦게 끝나는 경우를 보완하고, 새 주 난이도가 완료됐는데 보조 계산은 실패한 경우 이전 연주의 값을 새 결과로 붙이지 않는다. 분석 초기화·키 배치/모드 변경·앱 종료 시 보존값을 지운다.

보조 완료값은 높은 주 난이도 구간 주변에서 관측한 입력 특징이다. 별도 비동기 계산이므로 최고 난이도와 정확히 같은 시점의 값이나 곡 전체 평균이 아니며 플레이어 실력을 뜻하지 않는다.

## 다운로드와 사용

- `KeyNoteOverlayCpp-v2.16.1-Windows-x64.zip`: 일반판. osu! 선곡 연동은 매 실행 OFF이며 직접 동의 후 켠다.
- `KeyNoteOverlayCpp-v2.16.1-NoOsuMemory-Windows-x64.zip`: 게임 메모리 리더와 선곡 연동 UI를 컴파일에서 제외한다.
- `KeyNoteOverlayCpp-v2.16.1-SHA256SUMS.txt`: 위 ZIP의 SHA-256. ZIP 내부에도 파일별 체크섬을 제공한다.

새 폴더에 풀고 `KeyNoteOverlayCpp.exe`를 실행한다. 배포 기본 배치는 8K다. 기존 프로그램 종료 후 사용하던 JSON/INI를 새 폴더에 복사하면 배치를 이어 쓸 수 있다. 이전 릴리즈·개인 설정은 보존한다.

Discord 등 외부 앱의 채팅을 제외하려면 **위치 · OBS → 게임용 모드 → 적용 + 저장**을 켠다. 게임 내부 채팅과 실제 연주를 구분하는 기능은 없고, 완료 전 10초 안에 등록 키를 누르면 완료 시점이 늦어질 수 있다.

## 검증 범위

직접 입력의 649/650px·299/300px 경계, 반복 축소, 이전 JSON/INI의 보정과 원본 보존, 레인 접기 후 실제 창 최소 크기를 검사한다. 합성 입력으로 완료 후 보존·짧은 새 입력·다음 연주 결과 교체·연주 중 입력 패턴에 따른 보조값 갱신을 확인한다. 650px의 완료/실시간 HUD를 자체 비트맵으로 렌더링한다. 기존 수식 대조, 설정·리포트·트레이, NoOsuMemory 바이너리 경계 검사도 포함한다.

일반판과 NoOsuMemory 각각 CTest **11/11** 통과. 실시간 계산 **262개**, 네이티브 UI 일반판 **302개**·NoOsuMemory **286개** 검사를 통과했다. 검증된 빌드별 결과와 소스 커밋은 패키지 `VERIFICATION.md`에 기록한다. 실제 게임·OBS 캡처·다른 PC/DPI·장시간 사용은 미검증이다. [완료값 동작](completed-results-hotfix.md) · [CPP 계산 범위](revive-cpp-auxiliary.md)
