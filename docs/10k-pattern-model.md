# 10K BMS 개별 단위 비교 v2.8 — 과거 기록

v2.12의 현재 10K 기준은 [Revive 2026](revive10-reference.md)으로 교체했다. 아래 Tryr 기준점과 12코스 검증은 과거 기록이다. 패턴 부담 특징식은 유지한다.

Tryr의 `10K BMS Dans Phase I~III` 12코스를 기존 strain 하나로 비교하면 3/4단, 5/6단, 10단/Kaiden의 순서가 역전됐다. v2.8은 **10키에만** 누름에서 얻은 패턴 특징을 추가한다. 4K·7K·8K 기준표와 5K 보정은 바꾸지 않는다.

## 계산

최근 8초에서 15ms 동시 입력 묶음을 만들고 다음 부담을 계산한다.

```text
10K 패턴 부담 = strain ★
               + 1.6 × 조합 변화량
               + 0.5 × 리듬 변화량
               + 0.4 × 같은 열 반복 부담
               + 0.1 × 인접 묶음 반복 부담
```

| 특징 | 정의 |
| --- | --- |
| 조합 변화량 | 서로 다른 키 조합 수 / 8초. 단일 키도 조합에 포함한다. 시작 직후 짧은 경과 시간으로 나누지 않아 초기 과대평가를 방지한다. |
| 리듬 변화량 | 입력 묶음 사이 20~1,000ms 간격의 분포 엔트로피. 정렬된 간격을 첫 간격 기준 `max(12ms, 20%)` 허용치로 묶으며 작은 차이를 연쇄 연결하지 않는다. 최대 2.5비트, 간격 32개 미만에서는 표본 수에 비례해 줄인다. |
| 같은 열 반복 부담 | 각 열의 재입력에 `max(0, 1−간격/250ms)`를 합산한 초당 값. 중간에 다른 열이 눌려도 측정한다. |
| 인접 묶음 반복 부담 | 바로 앞 입력 묶음과 겹친 키 수에 같은 250ms 가중치를 적용한 초당 값. |

반복 부담의 분모는 기존 NPS처럼 경과 시간 2~8초다. 추가 특징에는 키를 뗀 시각이나 홀드 길이를 넣지 않는다. **LN 추가 부담 2/3은 strain에 그대로 적용**하며, 새 항으로 LN 보정을 상쇄하지 않는다. NPS 숫자는 기존 최근 1초 입력 수다. 이전과 같은 8초 평가·10초 종료 대기를 사용한다.

위 계수는 이 12코스의 순서 분리와 작은 타이밍 변화 검사를 기준으로 조정한 경험적 값이다. 공식 osu! 별점이나 보편적인 패턴 난이도 법칙은 아니다. 설정의 `참고 ★`는 기존 strain이고, `패턴`은 새 비교 부담이다. 실시간 표시, 완료 결과와 진행 막대가 모두 새 부담을 사용한다.

## 기준과 검증

기준 코스는 기존처럼 LN 가중치 1로 재생한다. 2초 간격의 8초 창 중 **새 부담이 가장 큰 세 창**의 평균을 기준점으로 삼는다. 실제 입력도 같은 특징 계산을 사용하며 LN 가중치만 사용자 요청대로 2/3다. 기준값 중간에서 다음 단위로 바꾸고 low / mid low / 수준 / high를 유지한다.

| 이전 묶음 | 새 기준점 |
| --- | --- |
| 3~4단 | 3단 6.92009 / 4단 8.06968 |
| 5~6단 | 5단 10.9759 / 6단 11.2286 |
| 10~개전단 | 10단 16.1435 / 개전 17.067 |

12코스 모두 기준점 순서가 증가하며 개별 단계로 표시된다. 생성 도구는 10K 기준이 다시 역전되면 실패하며, 이름만 강제로 순서대로 붙이지 않는다. 가장 가까운 기준은 5/6단으로 약 2.3% 차이다. 경계 근처의 실제 입력은 오갈 수 있다.

[합성 변화 검사](10k-pattern-validation.json)는 같은 12코스를 재사용한 검사다. 독립 채보나 실제 플레이 정확도 검증이 아니다.

- ±3ms 개별 노트 흔들림 두 시드: 24/24코스가 원래 단위 유지. 비교 부담 변화 최대 약 0.58%.
- 좌우 반전: 12/12 유지.
- 0.98배속: 12/12 유지. 1.02배속: 10/12 유지, 5단과 9단은 각각 한 단계 상승.
- 2초 간격 평가 위치와 패턴 분포가 바뀌므로 속도 변화에 부담이 항상 단조 증가한다고 보장하지 않는다. 1.02배속의 2단은 약 0.94% 감소했지만 단계는 유지했다.

단위별 모든 구간을 해당 단위로 맞추는 것이 아니다. 쉬운 구간은 낮게 나올 수 있고, 개인별 기술·체력·게임 판정·놓친 노트는 읽지 않는다. 조합·리듬 변화량도 채보의 의도를 알지 못하므로 실제 플레이에 대한 별도 보정은 여전히 필요하다.

## 재현

선택한 10K 코스를 별도 폴더에 추출한 뒤 네이티브 계산기로 측정한다. 아래 결과 경로는 새 경로여야 한다. 노트 사본은 Git/배포에 포함하지 않는다.

```powershell
python -B tools/prepare_dan_reference.py --keys 10 --root <course-library> --output build-cpp-settings/reference-10k-new
cmake --build build-cpp-settings --target pattern_features
build-cpp-settings/pattern_features.exe build-cpp-settings/reference-10k-new --windows
python -B tools/validate_10k_patterns.py build-cpp-settings/reference-10k-new --extractor build-cpp-settings/pattern_features.exe --output build-cpp-settings/10k-perturbations-new --report docs/10k-pattern-validation.json
```

`features.tsv`의 비교값 열은 10K에서 새 패턴 부담, 다른 키 모드에서는 기존 strain이다. `--windows`는 구간별 원래 strain·새 부담·특징을 별도의 `windows.tsv`에 기록한다. 앱은 이 오프라인 도구를 실행하지 않는다. v2.10의 선택형 [연주 리포트](session-reports.md)는 별도로 등록 레인의 타이밍과 실시간 분석값을 로컬 HTML에 저장한다.
