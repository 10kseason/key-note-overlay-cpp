# AERY 5K 보조 기준 v2.13

기존 **34개 단조 보정점은 바이트 단위로 보존**하고, 학습용 채보에서 선정한 **230개 보조 기준**을 실시간 추정에 더한다. 기존 ⑤1~10 피드백 보정과 LN 추가 부담 2/3도 유지한다. 34개 점은 34곡을 뜻하지 않으며 기존 학습용 1,346채보를 요약한 곡선이다. 이번 보조 기준은 같은 자료에서 고른 대표 표본으로, 새로운 독립 채보 230개를 수집한 것은 아니다.

## 선정과 부족한 레벨

원래 특징 파일의 MD5·폴더 그룹·학습/검증 분할을 고정한다. 같은 레벨과 폴더 그룹 안에서는 특징값 중앙에 가까운 채보 하나만 대표로 삼고, 레벨별 특징값 범위에 고르게 걸치도록 10개를 선정한다. 폴더 그룹은 곡 구분을 위한 대용 지표이며 다른 폴더에 복제된 곡까지 완벽하게 제거했다는 뜻은 아니다.

| 레벨 | 선정한 보조 채보 |
| --- | ---: |
| ⑤1 | 2 |
| ⑤2 | 3 |
| ⑤3 | 6 |
| ⑤4 | 7 |
| ⑤5 | 4 |
| ⑤7 | 8 |
| 나머지 20개 레벨 | 각각 10 |

부족한 여섯 레벨은 사용자 선택에 따라 **학습용으로 확보한 그룹 전부**를 쓴다. 검증용 328채보는 부족분을 채우는 데 사용하지 않는다. ⑤15+부터의 `+` 레벨도 각각 별도로 취급한다. 자세한 26레벨 구성과 230개 MD5는 [집계 JSON](aery-auxiliary-reference.json)에 있다.

전체 230채보는 서로 다른 폴더 그룹 200개에서 왔다. 같은 곡의 다른 난이도는 서로 다른 레벨의 대표가 될 수 있지만, 한 레벨 안에서 같은 그룹을 두 번 세지는 않는다.

## 실시간 적용

`x = strain + ln(1 + NPS8)`, `y = ln(1 + NPS8)`, 원래 보정 곡선의 값 `L = C34(x)`로 둔다. 각 보조 채보의 잔차는 `표 등급 - C34(채보 x)`다.

```text
w_i = exp(-0.5 × (((x-x_i)/0.35)^2 + ((y-y_i)/0.8)^2))
보조 변화량 = clamp(0.2 × Σ(w_i × 잔차_i) / (Σw_i + 1), -0.5, +0.5)
저레벨 감소량 = clamp((13-L)/2, 0, 1)
최종 등급 = max(1, L + 보조 변화량 - 저레벨 감소량)
```

유사한 표본이 드물면 분모의 `+1`로 변화량을 줄인다. 원래 보정 범위 밖이나 유효하지 않은 입력에는 보조 변화량을 0으로 한다. 저레벨 감소량은 보조 적용 전 `L`에서 계산해 수동 보정량이 다시 변하지 않게 한다. 기존 곡선 자체는 단조성을 유지하지만 두 특징을 사용하는 보조 변화량은 단조성을 별도로 보장하지 않는다.

설정·HUD·연결 대기·완료 결과·새 리포트는 추정기의 최종값을 공유한다. 저장된 기존 리포트는 바꾸지 않는다. strain·NPS·다른 키 모드의 계산은 그대로이며 추가 파일이나 원본 채보를 실행 시 읽지 않는다.

## 검증과 한계

학습 그룹의 고정 4분할로 45가지 폭/강도 후보를 비교하고 매개변수를 정한 뒤, 보류 표본은 한 번 평가했다. 보조 표본과 평가 그룹은 겹치지 않는다. 원래 C34는 전체 학습 그룹으로 이미 맞춘 고정 곡선이므로 이 교차 검증은 **보조 단계의 증분 비교**이며 전체 학습을 처음부터 다시 한 검증은 아니다.

| 보류 328채보, LN 추가 부담 1 | 보조 적용 전 MAE | 보조 적용 후 MAE | 오차 80% 폭 전 → 후 |
| --- | ---: | ---: | ---: |
| 원래 C34 | 0.530967 | 0.524226 | 1.000000 → 0.943600 |
| 기존 저레벨 감소량 포함 | 0.541709 | 0.539949 | 0.993131 → 0.934362 |

원래 C34 대비 MAE 개선은 약 1.27%로 작다. 교차 검증에서는 0.553914 → 0.553456이었다. 보류 표본에서 관측한 최대 변화량은 0.108864단계이며 구현의 상한은 ±0.5다. 사전에 정한 교차 검증 개선·보류 MAE 1% 이상 개선·오차 80% 및 저레벨 경로 비악화 조건을 통과했다. 보류 결과를 보고 매개변수를 다시 조절하지 않았다.

이 수치는 기존 **LN 가중치 1의 채보 특징**에 대한 비교다. 실제 입력·놓친 노트·게이지·개인차나 기본 LN 2/3 모드의 정확도가 검증된 것은 아니다. 화면의 기존 `±1.0`은 과거 보정 오차이며 이번 결과로 실시간 신뢰구간을 주장하지 않는다. 낮은 레벨의 표본 수가 적고 레벨 간 근접 패턴은 여전히 혼동될 수 있다.

추가 회귀 검사에서는 119개 합성 입력 중 다른 키 모드 102개가 모든 출력에서 같았고, 5K 17개는 등급을 제외한 strain·NPS·입력 지표가 같았다. C++ 보조 계산은 숫자 기준점·합성 입력 1,209개에서 독립 Python 구현과 일치했다.

## 재현

```powershell
python tools/build_aery_auxiliary.py --features build-cpp-settings/calibration/features.tsv --base src/calibration_tables.h --header src/aery_auxiliary_reference.h --report docs/aery-auxiliary-reference.json
python -B -m unittest discover -s tests -p test_aery_auxiliary_tools.py -v
```

입력 특징과 C34 파일의 SHA-256이 기존 값과 다르면 도구가 실패한다. C34는 Git에서 쓰는 LF와 Windows의 CRLF 원본 두 형식만 허용하며 내용 변경이나 혼합 줄바꿈은 거부한다. 채보·이벤트·개인 절대 경로는 Git/배포에 포함하지 않는다. 배포 헤더에는 숫자 특징과 잔차만 있고 JSON에는 해시·집계·검증 결과만 있다. 도구는 고정 모델과 기록을 재현하기 위한 것이며 반복 실행 결과로 보류 표본에 맞춰 조절해서는 안 된다.
